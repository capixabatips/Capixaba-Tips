# Capixaba Tips

Dashboard visual responsivo para análises esportivas.

## Publicar gratuitamente no GitHub Pages

1. Crie um repositório público chamado `capixaba-tips`.
2. Envie `index.html`, `style.css`, `app.js` e a pasta `assets`.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a publicação.

## Próxima etapa

Esta versão é a interface/front-end. Para análises automáticas, odds em tempo real e envio para WhatsApp/Telegram, será necessário conectar uma fonte de dados/API e um backend/automação.

Os exemplos exibidos no painel são demonstrativos e não representam garantia de resultado.
